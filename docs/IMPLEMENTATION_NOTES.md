# 구현 정리

## 1. Figma Make 디자인 반영 범위

Figma Make에서 생성된 코드는 TypeScript/TSX 구조였고, UI 방향은 다크 네온, 파티클 배경, 단계형 추천 입력, 결과 카드 플립 인터랙션이었습니다. 이번 작업에서는 해당 디자인 방향을 유지하되, 프로젝트 요청에 맞춰 React JS/Vite 구조로 새로 구성했습니다.

## 2. 백엔드 구조 변경

기존 `recommend_laptop.py`는 사용자가 터미널에서 직접 값을 입력하고 `recommend_result.txt`로 결과를 저장하는 CLI 구조였습니다. 웹에서는 입력과 결과가 화면에서 즉시 처리되어야 하므로 다음 구조로 변경했습니다.

```text
CLI input/output
→ REST API request/response
→ React 화면 렌더링
```

## 3. 추천 로직 유지

기존 점수 기준은 유지했습니다.

- 학과 권장 CPU 충족
- 학과 권장 RAM 충족
- 학과 권장 저장공간 충족
- 학과 권장 GPU 충족
- 예산 이내/예산 경계/예산 초과
- 성능 우선순위 가중치
- 휴대성 우선순위 가중치
- 과도한 저장공간에 따른 가격 왜곡 감점
- 가격 우선순위가 아니더라도 입력 예산 대비 과도하게 높은 제품 감점

## 4. 프론트엔드 구성

- `App.jsx`: 화면 전환, API 호출, 결과 상태 관리
- `Wizard.jsx`: 회원 정보/학과/예산/우선순위/OS 입력
- `Results.jsx`: 추천 결과 헤더, BEST PICK, TOP 5, 비교표
- `LaptopCard.jsx`: 노트북 카드 앞/뒤 플립 UI
- `ParticleField.jsx`: 배경 파티클 애니메이션
- `CursorGlow.jsx`: 마우스 글로우 효과
- `styles.css`: 전체 UI 토큰, 반응형, 애니메이션
